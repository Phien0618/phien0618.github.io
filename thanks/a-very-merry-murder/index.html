Get ready in 20 minutes

  1. Read Start Here and the Host Guide. Don't read the Solution until you've assigned the roles, unless you'd rather know the answer first.
  2. Use the cast table to choose roles for your number of guests. The 6 core roles are always needed.
  3. Send each guest their character and costume idea using the invitation wording.
  4. Print one booklet per player, one set of evidence cards and one ballot per player. Black and white is fine, and "Fit to page" works for both Letter and A4.
