Word list format

One entry per line. Separators: Tab (two spreadsheet columns), =, | or - . Lines starting with # are categories (column titles in Quiz Board). 5–100 entries.
# Animals
elephant = a big grey animal with a long nose
rabbit | 兔子 (tùzi)
apple - りんご · 사과

One list, every game

The list you paste here travels with you: it is passed to the game inside the link, so it works in Chrome, Edge, Safari and Firefox, even with no internet. Inside any game, click ▦ Games to jump to another game with the same list. Save up to 200 named lists in this browser. To move lists to another computer, use Export .txt in a game, then Import .txt.

Help & printouts

Press ? in any game for the rules and keys. Space = start/next, F = full screen, Esc = close.
