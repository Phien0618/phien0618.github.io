How to use it

  1. Unzip the ZIP (or download the HTML file). Copy it to the classroom computer or a USB stick.
  2. Double-click ESL-Phonics-Games.html. It opens in current Chrome, Edge, Firefox or Safari with no internet (Internet Explorer is not supported). In Safari, right-click the file and choose Open With → Safari.
  3. Tick the sound units you are teaching (for example short a + sh), choose 2–6 teams, pick a game and press F for full screen.
  4. There is no word audio: you model the sounds. Use the sound buttons under the words to blend together.
  5. To add your own words, open My word lists and type one word per line: sh-i-p marks sound chunks, cat = 猫 adds a meaning, *vab adds an alien word.
  6. Your lists live in this browser's local storage. Export them as .txt before clearing the browser cache or moving to another computer, then import them there.
  7. Read the 1-page Quick Start first; the Teacher Guide has one page per game and a 30-minute sample lesson. Print the Word Bank page for a unit as a take-home reading list.
