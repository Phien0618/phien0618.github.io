FREELANCE CLIENT & INVOICE TRACKER · README
===========================================

OPEN FIRST: freelance-client-invoice-tracker.xlsx
Then read the guide (Letter or A4 PDF), Chapter 1: setup takes about 10 minutes.

THE 7 FILES
1. freelance-client-invoice-tracker.xlsx     the workbook, 8 tabs (Excel 2016+ or Google Sheets)
2. freelance-client-invoice-tracker-letter.pdf   the guide, 18 pages, US Letter
3. freelance-client-invoice-tracker-a4.pdf       the same guide, 18 pages, A4
4. invoice-template.html     1-page client invoice: open in a browser, click to edit,
                             Letter/A4 switch, Print / Save as PDF. Works offline.
5. invoice-template.md       the same invoice as text for Google Docs, Word or Notion
6. reminders-and-replies.txt the 4 reminder emails, 6 excuse replies, terms wording
                             and the late-fee clause example, ready to copy
7. README.txt                this file

GOOGLE SHEETS
Google Drive > New > File upload > choose the .xlsx, then open it with Google Sheets.
Or in Sheets: File > Import > Upload > choose the file > Replace spreadsheet.

GOOD TO KNOW
- Cream cells = type here. White cells = formulas (don't type over them).
- Dropdowns: Source (Clients), Stage (Projects), Terms (Invoices), Late fee (Settings).
- Dashboard is locked without a password (Review > Unprotect Sheet).
- No native charts (text bars instead). Add one in 30 seconds: guide FAQ, page 16.
- No macros, no scripts, no automatic emailing: the tracker writes the emails,
  you copy and send them.
