FREELANCE PRICING & QUOTE KIT (v3), by Hustle Studio
=====================================================

OPEN FIRST: freelance-pricing-kit.xlsx -> "Start Here" tab, then "Floor Rate".
Then read the guide (PDF) alongside it, Chapters 1 and 2.

FILES (9 in the ZIP; the download page also links each one separately)
- freelance-pricing-kit.xlsx ........ THE MAIN TOOL. Workbook, 6 tabs: Start Here, Floor Rate,
                                       Market Check, 3-Tier Quote, Change Order, Rate Increase.
                                       Yellow = your input, blue = formula (locked).
                                       Sheets are protected WITHOUT a password; tier and
                                       rush-multiplier cells have dropdowns.
- freelance-pricing-kit-letter.pdf .. The guide (29 pages, 6 chapters), US Letter.
- freelance-pricing-kit-a4.pdf ...... The same guide, A4. Print whichever matches your paper.
- quote-template.html ............... Client-facing 2-page quote. Open in any browser, click a yellow
                                       field to edit, then "Print / Save PDF" (Letter or A4 button).
                                       Deposits are calculated from each price and the Deposit % box.
- quote-template.md ................. The same quote as text, to paste into Google Docs, Word or Notion.
- scripts-and-templates.txt ......... Every email and script from the guide as plain text, §1 to §10.
- pricing-calculator.html ........... Offline browser calculator: floor rate, 3 packages, per-word ->
                                       hourly, monthly retainer fee, 12-month rate-increase cash flow.
- pricing-sheet.csv ................. FALLBACK ONLY, for apps that can't open .xlsx. Plain CSV of the
                                       floor-rate and package math: no formatting, no extra tabs.
                                       Use the .xlsx if you can.
- README.txt ........................ This file.

OPEN THE XLSX IN...
- Excel (Windows/Mac): double-click the file.
- Google Sheets: go to sheets.google.com -> File -> Import -> Upload -> choose
  freelance-pricing-kit.xlsx -> "Create new spreadsheet". (Or upload it to Google Drive and
  open it with Google Sheets.)
- Apple Numbers / LibreOffice: open the file directly.

CHECK IT WORKS
With the example values (Maya, a fictional brand designer) you should see:
floor rate 90, day rate 720, packages 1,900 / 2,700 / 3,250, deposits 950 / 1,350 / 1,625.
Calculator Step 4 (Theo, fictional writer): retainer 1,750 a month. Step 5: +7,260 after 12 months.
Amounts are currency-neutral: use your own currency.
