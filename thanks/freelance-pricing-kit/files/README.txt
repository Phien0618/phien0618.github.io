OPEN FIRST: freelance-pricing-kit.xlsx -> "Start Here" tab, then "Floor Rate".
Then read the guide (PDF) alongside it, Chapters 1 and 2.

FILES
- Freelance-Pricing-Kit-All-Files.zip  Everything below in one download.

- pricing-calculator.html ........... Offline calculator (floor rate + 3 packages) if you have no

OPEN THE XLSX IN...
- Excel (Windows/Mac): double-click the file.
- Google Sheets: go to sheets.google.com -> File -> Import -> Upload -> choose
  freelance-pricing-kit.xlsx -> "Create new spreadsheet". (Or upload it to Google Drive and
  open it with Google Sheets.)
- Apple Numbers / LibreOffice: open the file directly.

CHECK IT WORKS
With the example values (Maya, a fictional brand designer) you should see:
floor rate 90, day rate 720, packages 1,900 / 2,700 / 3,250, deposits 950 / 1,350 / 1,625.
Amounts are currency-neutral: use your own currency.
