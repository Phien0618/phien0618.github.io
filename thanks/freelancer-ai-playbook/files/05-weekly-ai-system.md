# 05 – The Weekly AI System
### A 90-minute Friday routine to keep your freelance business growing

---

## Why a Weekly System?

Many freelancers live in reaction mode. They finish projects, invoice, find the next thing in a panic, repeat. The cycle feels busy but it's not compound growth — it's a treadmill.

A weekly system changes that. 90 minutes every Friday (or whenever your work week ends) turns your business from reactive to intentional. Give it 12 weeks before judging whether it works for you.

---

## The Full 90-Minute Block

Set a timer for 90 minutes. No meetings. No emails (except what the system asks you to send). Work through these five parts in order.

---

### Part 1 – Weekly Review (20 minutes)

Open a doc and write raw answers to these questions. Don't edit — just write.

1. What did I complete this week?
2. What didn't I complete? Why?
3. Where did time go that I didn't plan for?
4. What would have made this week better?
5. What's the single most important thing I learned this week?

**Then** paste your answers into AI with this prompt:
> "Here are my weekly review notes. Identify: (1) one pattern across the items, (2) one thing I seem to be avoiding, (3) one specific process improvement I should make next week."

Read the output. You don't have to act on all of it — but if something resonates, write it down as a change.

|---|---|---|---|---|
| [CLIENT 1] | | | | |
| [CLIENT 2] | | | | |

**Action items:**
- If any client hasn't heard from you this week: send a status update (prompt D1).
- If any deliverable is at risk: flag it now (prompt D4).
- If any client seems unhappy: address it before the weekend (prompt D9).

**Rule:** No client should go more than 5 business days without a touchpoint during an active project.

### Part 3 – Pipeline & Business Development (20 minutes)

| Prospect | Last contact | Status | Next action | By when |
|---|---|---|---|---|
| [PROSPECT 1] | | | | |
| [PROSPECT 2] | | | | |
| [PROSPECT 3] | | | | |

1. Do I have enough in the pipeline to hit next month's income goal? (If no: what's one BD action I can take today?)
2. Is there a past client I haven't spoken to in 3+ months? (If yes: send a check-in today.)
3. Is there a referral I should ask for? (If yes: use prompt A7 and send it today.)

**Content and visibility (5 min)** — if you're building an audience:
- Did I publish anything this week?
- Is there one thing I learned this week that would be useful to my audience?
- If yes: spend 5 minutes drafting a post using prompt E2. If it's good, post it.

**Monthly run rate:** Compare this month to the last 3. Trending up, flat, or down? If down two months in a row, treat it as a signal to double BD effort, not just wait.

---

### Part 5 – Next Week Setup (20 minutes)

**Step 1 – Prioritize next week.** Top 3 deliverables:

1. ________ (for client ________, due ________)
2. ________ (for client ________, due ________)
3. ________ (for client ________, due ________)

These go in your calendar as time blocks before anything else.

**Step 2 – Identify what needs AI help.** For each deliverable:
- Most uncertainty? → Use AI for research or outlining first.
- Most time-consuming? → Use AI for first drafts.
- Most expertise? → Block focused time, no AI shortcut.

**Step 3 – Capture one process improvement** from Part 1:
> "Next week I will [SPECIFIC CHANGE] in order to [EXPECTED BENEFIT]."

**Step 4 – Clear your head.** Write down anything bugging you — a client situation, a financial concern, a conversation you're avoiding. For each, write one concrete next step, even if tiny.

---

## Monthly Add-On (First Friday of Each Month, +30 min)

**1. Income & goal review (10 min)** — income vs. goal, last 3 months, are rates creeping up?

**2. Client audit (10 min)** — best work? most enjoyable? most stressful? anyone to wind down or raise rates with?

**3. Skills check (10 min)** — one skill to develop in the next 90 days; one course, book or community to engage with this month.

---

## Quarterly Add-On

Once per quarter, run prompt **E8** adapted for quarterly use. Key questions:

1. Am I on track to hit my annual income goal?
2. What's my highest-revenue service or client type? Am I leaning into it?
3. What am I still doing that I should stop?
4. What's one thing I'll do differently next quarter?

---

## Making It Stick

- **Name it.** "Friday Review" or "CEO Hour" — make it a recurring calendar event.
- **Don't skip it, shorten it.** With only 30 minutes, do parts 2, 3 and 5.
- **Keep the log.** It's worth 5 minutes of the 90.
- **Share it (optional).** A weekly note to a peer adds accountability.
