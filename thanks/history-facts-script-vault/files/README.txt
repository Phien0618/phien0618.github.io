IMPORT THE CSV FILES
All CSV files are UTF-8, comma-separated, with a header row.
Google Sheets: File > Import > Upload > choose the CSV > Import location "Insert new sheet(s)" >
  Separator type "Comma" > Import data.
Excel (Windows and Mac): Data > From Text/CSV (Get Data > From File > From Text/CSV) > choose the CSV >
  File Origin "65001: Unicode (UTF-8)" > Delimiter "Comma" > Load.
  (Opening the file by double-click can show curly quotes or accents wrongly; use the import above.)
Tip: in script_beats.csv, filter by script_id to get an edit list for one video.
You can add your own rows to hooks.csv; it is a plain spreadsheet (there is no generator).

VERIFY BEFORE POSTING
The facts come from widely documented history, but we are not professional historians.
Check each fact against the named reference on the "Verify with" line before posting,
and read the "Myth check" line so you don't repeat the popular wrong version.
Use only images you have the rights to (public-domain paintings and maps, museum open-access
images, your own drawings), and follow each platform's AI-disclosure rules.
Nothing in this pack promises views, followers or income.
