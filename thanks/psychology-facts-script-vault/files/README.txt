IMPORT THE CSV FILES
All CSV files are UTF-8, comma-separated, with a header row and every text field in double quotes.
Google Sheets: File > Import > Upload > choose the CSV > Import location "Insert new sheet(s)" >
  Separator type "Comma" > Import data.
Excel (Windows and Mac): Data > From Text/CSV (Get Data > From File > From Text/CSV) > choose the CSV >
  File Origin "65001: Unicode (UTF-8)" > Delimiter "Comma" > Load.
  (Opening the file by double-click can show curly quotes wrongly; use the import above.)
Tip: in script_beats.csv, filter by script_id to get an edit list for one video.
You can add your own rows to hooks.csv; it is a plain spreadsheet (there is no generator).

EVIDENCE TAGS
Well supported    = repeatedly replicated, or textbook consensus.
Mixed             = a real effect, but smaller, debated or limited to some conditions.
Did not replicate = a famous claim that large replication attempts did not confirm.
The voiceover wording matches the tag. Count in this pack: 41 Well supported, 12 Mixed, 7 Did not replicate.

VERIFY BEFORE POSTING
The scripts are written from widely documented psychology and our build process checked them for
internal consistency, but we are not psychologists, and no outside expert reviewed the scripts.
Check each claim against the named reference on the "Verify with" line before posting, and read the
"Myth check" line so you don't repeat the popular wrong version.
This is educational entertainment, not mental-health advice or diagnosis.
Use only visuals you have the rights to (licensed stock, your own graphics, public-domain images),
never clips from TV shows or films, and follow each platform's AI-disclosure rules.
Nothing in this pack promises views, followers or income.
