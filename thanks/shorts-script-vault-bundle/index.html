How to use it

  1. Open the Bundle Guide first. Page 2 maps every file; page 3 explains the merged CSV.
  2. Pick a niche and length. Open ALL-NICHES_scripts.csv in Google Sheets (File → Import → Upload) or Excel (Data → Filter), filter niche and length_s (30, 45 or 60).
  3. Voice it. Copy full_voiceover into your text-to-speech tool or read it yourself.
  4. Edit it. Filter ALL-NICHES_script_beats.csv by the same uid (e.g. ANI-S41) for start and end seconds, visual and caption cues.
  5. Check facts before posting. Fact scripts name a “Verify with” source; confirm the claim there, then apply the “Make it yours” swaps so your video is your own.

CSVs are UTF-8. If curly quotes look odd in an older Excel, use Data → From Text/CSV and choose UTF-8.
