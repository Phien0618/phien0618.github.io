OPEN THE CSV FILES
All CSV files are UTF-8, comma-separated, with a header row.

Google Sheets:
  File > Import > Upload > choose the .csv file > Import location: "Insert new sheet(s)"
  > Separator type: Comma > Import data.

Excel (Windows or Mac):
  Data > From Text/CSV (Get Data > From File > From Text/CSV) > choose the file
  > File origin: 65001: Unicode (UTF-8) > Delimiter: Comma > Load.
  (Double-clicking the file can garble apostrophes and quote marks in some Excel
  versions; the import route above keeps them correct.)

Tip: in script_beats.csv, filter by script_id to get a beat-by-beat edit list
for one video.

VERIFY BEFORE POSTING
Every script has a "Verify with" line naming where its core claim can be checked
(a NASA, NASA Space Place, JPL, ESA or Encyclopaedia Britannica page title; no URLs).
The scripts are written from widely documented astronomy, and our build process
checks them for internal consistency. We are not astronomers, and no outside
expert reviewed the scripts. Check each claim against the named reference
before posting.

RE-CHECK NUMBERS
12 scripts are tagged "Re-check numbers" (S06, S18, S22, S30, S35, S41, S44, S46,
S48, S52, S55, S56). They contain a count, record or mission status that can
change, such as Saturn's moon count, the number of confirmed exoplanets or
whether a spacecraft is still active. The voiceover hedges the figure ("more than",
"about", "as of the mid-2020s"), the PDF highlights the words to update, and the
"Re-check:" line (the recheck column in scripts.csv) names exactly what to confirm.
Confirm that figure in the named reference on the day you post.
The other 48 scripts are tagged "Evergreen": physics and long-settled facts.

Visuals: the Visual column names a type of visual, not a file. Many NASA images are
public domain, but agency logos and insignia are not free to use, and ESA and other
agencies' images have their own licences. Check each image's credit line. Label
artist's impressions and AI images as illustrations. Never use clips from films,
TV shows or other creators. Follow each platform's AI-disclosure rules.
