3. How to use it

  1. Read 00 Start Here first. It explains every file and gives the print list for 6–14 players.
  2. Party this weekend? Open the Host Guide: page 3 has the 1-hour prep plan and a 28-page minimum print list for 6 players.
  3. Cast and invite. Use the casting chart in the Host Guide (6 core booklets, then optional ones in order; pairs for 15–20 guests). Send printed invitations, an E-Invite or the text version.
  4. Print at 100% from the folder that matches your paper. Print booklets single-sided (or cut page 3 on its dashed line) so later rounds can't show through. A helper, not the Detective, cuts the evidence cards.
  5. Don't open file 99 until after the vote: a player reads the sealed solution aloud, so the host can play Detective Ira Gilchrist and guess too.
