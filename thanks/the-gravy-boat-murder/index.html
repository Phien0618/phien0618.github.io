3. How to use it

  1. Pick one paper size. US Letter for the US and Canada, A4 almost everywhere else.
  2. Read 00 Start Here first. It explains who may see which file and gives the exact print list for 6–12 players.
  3. Read the Host Guide (01). It has no spoilers, so you can still play. Use the casting chart to pick booklets for your head count: 10–15 are always used, 16–21 join in order; the host can take booklet 10 or 11.
  4. Choose your version: Full (140 minutes), Express (90 minutes) or the 60-minute plan. All are in the Host Guide.
  5. Send invitations (file 02, or the text version on its last page) and each guest's booklet. Booklets are separate PDFs, so you can text or email one to each guest. Fill in the Potluck Planner (04) as dishes are confirmed.
  6. Ask a helper to cut the evidence cards (30) and fill three envelopes: Appetizers (E1–E4), Main Course (E5–E8), Pie (E9–E12), so the host doesn't see them either.
  7. Do not open file 99 before the party. Seal it in an envelope marked "Open last." After the ballots, a volunteer opens it and reads Script 5.
  8. Printing: print booklets single-sided (or cut page 3 on its dashed line) so later rounds can't show through. Everything works in black and white.
