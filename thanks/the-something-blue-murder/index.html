3. How to use it

  1. Pick one paper size. US Letter for the US and Canada, A4 almost everywhere else.
  2. Read 00 Start Here first. It explains who may see which file and gives the exact print list for 6–14 players.
  3. Read the Host Guide (01). It has no spoilers, so you can still play. Use the casting chart to pick booklets for your head count: the Guest of Honor always gets booklet 10; the host can take booklet 12 or 15.
  4. Choose your edition: Evening (150 minutes) or Shower (90 minutes). Both timetables are in the Host Guide.
  5. Send invitations (file 02, or the text version on its last page) and each guest's booklet. Booklets are separate PDFs, so you can text or email one to each guest.
  6. Ask a helper to cut the evidence cards (30) and fill the three round envelopes, so the host doesn't see them either.
  7. Do not open file 99 before the party. Put it in an envelope marked "Guest of Honor: open last." The Guest of Honor opens it after the vote and reads the reveal.
  8. Printing: print booklets single-sided so later rounds can't show through. Everything works in black and white.
